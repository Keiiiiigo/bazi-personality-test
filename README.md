# 生辰八字人格测试

输入出生日期，自动排盘并生成一份人格分析报告。点开链接就能测，不用注册、不用登录。

在线体验：https://keiiiiigo.github.io/bazi-personality-test/

## 能测到什么

- 三柱排盘：年柱、月柱、日柱的天干地支、藏干、五行、纳音、十神
- 五行统计：金木水火土的分布与偏旺 / 偏弱 / 缺失
- 日主强弱、月令旺衰、格局、用神
- 人格报告：4 个关键词 + 一句话总评，核心性格、优势天赋、盲点提醒、人际与情感、事业方向、成长建议 6 个板块
- 命理依据：报告里每条关键结论都附带出处，如《子平真诠》《滴天髓》，可在页面里展开查看
- 分享图：结果页可以生成一张分享海报，支持系统分享或保存图片

## 怎么用

1. 打开上面的在线链接
2. 填姓名（选填）、性别、出生日期（公历）
3. 出生地可选，精确到市，用于展示与真太阳时差参考
4. 点「开始排盘」，看报告；想分享就点「生成分享图」

## 技术说明

- 纯前端，单个 `index.html` 就能跑，不需要服务器、数据库和登录
- 用 [lunar-javascript](https://github.com/6tail/lunar-javascript) 做公历转农历与节气计算，年柱以立春为界，月柱以节气为界
- 所有计算都在浏览器本地完成，不上传出生信息
- 省市数据内置在页面里，不依赖外部接口

本地打开也很简单：下载 `index.html`，用浏览器直接打开即可。
